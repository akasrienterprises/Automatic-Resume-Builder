# Automatic Resume Builder
Professional Flask web application for creating, editing, saving and exporting resumes.

## Run locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## GitHub deployment
Push the folder to GitHub. For a live Python app, deploy the repository to a Python-compatible host such as Render/Railway. GitHub Pages cannot run Flask server-side code.

Set `SECRET_KEY` as an environment variable in production.
